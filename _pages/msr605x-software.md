# MSR605X Software Download for Android USB

EasyMSR USB is an Android application for compatible **MSR605X magnetic stripe readers and writers** connected through USB. Download the official Google Play version and confirm that your Android phone or tablet supports USB OTG.

## Requirements

- A compatible MSR605X USB reader/writer
- An Android phone or tablet with USB host/OTG support
- A suitable USB or USB OTG adapter
- Permission for EasyMSR USB to access the connected USB device

## Connect an MSR605X to Android

1. Install EasyMSR USB from Google Play.
2. Connect the MSR605X with the appropriate USB OTG adapter.
3. Open EasyMSR USB.
4. Approve the Android USB-device permission prompt.
5. Test a read operation to verify the connection.

## EasyMSR USB Features

- Read supported magnetic stripe tracks
- Write track data to compatible cards
- Copy supported track data
- Erase selected tracks
- Import and export data files

## MSR605X vs. MSRX6 Software

The MSR605X page is for **USB-connected Android hardware**. If your reader connects through Bluetooth and is identified as MSRX6 or MSRX6BT, use the [MSRX6 Bluetooth software page](/msrx6-software/).

## Troubleshooting

### Android does not detect the reader

Check that the phone supports USB OTG, reconnect the adapter and approve the USB permission prompt. If the reader requires more power than the phone supplies, use a suitable powered USB connection.
